# 海湾新生活 · 制作合同

2026-10-01，已接受方向，以下时间和数值是待实测的制作目标，不是已验证的玩家时长。

## 1. Overview
国际用户；现代虚构北美海湾小镇。玩家是租住一夏的新来者，和角色共同认识当地。中文仅协作/本地化，英文为完整主流程；跟随系统语言，可覆盖。不做高概念设定说明。
单次可投入10–25分钟，长期保留地点、物品、关系、完成的挑战与世界改变。序章目标8–12分钟，完整首章目标60–90分钟；实际最短路线另验，不用等待/回合数量凑时长。自然停止点为回家或完成一次委托。主线结束仍能探索。
循环：发现地点→观察/交谈→选择行动或操作挑战→世界产生可见变化→选择新的去处。
首个价值时刻：亲手修好咖啡馆里待修的露台灯，看到灯亮起，得到店员的招待。三问：当前在镇上安顿并寻找去处；反复探索、帮助和挑战；成果是路线/物品/关系变化，失败可以重试。新玩家理解尚未验证。

## 2. Visual Design
2D精灵、轴向斜俯视正投、独立地墙门家具；夏日盐白木屋、暖赭屋顶、蓝绿海湾、克制像素笔触。主角与NPC同屏等比例；家具主要轴向，45度点缀。上方轻量地点与地图/行囊/菜单/声音；左下圆摇杆、右下高对比行动按钮，中间留空。靠近才显示互动标记。交谈先介绍再给选项，已聊话题进入历史；支持自由询问。详见visual.md。

## 3. Game Mechanics
### 世界与进程
用户补充：不能把所有地点都当房间。五个主要区域采用1280×880以上的连续室外可走空间：街道、码头、海滩、山坡有不同地形/视野/用途。每个区域有双轴跟随镜头、中心地标、直接路线与绕行、安静过渡区。建筑入口嵌入户外，室内仍为小尺度空间；室外不用四面墙围起来，也不凭地面放大制造地图。角色与家具尺度固定。
五区：车站街、港口、旧街集市、海岸、山坡。15个固定可进入地点：租屋、咖啡馆、杂货铺；码头、修理铺、拳馆；集市、旧物店、庭院；沙滩、滨海道、灯塔；花园、营地、气象站。户外具有分支、回路和地标，不靠连续串房。
序章：抵达→房东自我介绍→拿钥匙安顿→咖啡馆取回包裹→自选协助修理→开放外出目标。主线：了解封闭海岸路线→收集损坏/通行与居民顾虑证据→选择修桥或安排替代通路→与相关居民达成使用安排→开启夏日集市。各区域有独立可完成的小故事与后果；私人庭院不因主线强制开放。
三项持久数值：体力0–100，现金0–999，当地口碑0–100；起始100/$25/0。自由行走不收费；一次承诺的体力劳动暂定耗10，家中免费休息恢复100。声望不等于所有NPC的信任，人物关系单独记录。第一次修理教学不扣体力，无软锁。
背包分工具、物件、笔记；已用与已交付有历史，数量和来源可查；肖像/资料可放大。地图分区域与地点，访问过的安全地点可快捷前往，挑战中不可跳过结算。
### 通用战斗（新能力，待验证）
单人实时：移动、攻击、防御动作。规则按60Hz固定步进；画面帧率不改变出手时机。动作阶段预备/有效/收招，命中同一出手每目标一次；脚底碰撞与身体受击区域分离。
基础拳击：玩家5格状态、对手4格；攻击预备0.12s/有效0.10s/收招0.28s；闪避0.22s、冷却0.8s；对手预警0.65s。初次训练无损失。原型以1名对手为主，扩展到2名。支持击败、坚持20s、到达区域三种目标。近战与一种直线投射物；模板不写死小镇人物、拳击、美术与奖励。
切磋不强制；失败无现金惩罚，可重试/离开。权威记录开始、检查输入与结果、一次结算；刷新不重发奖励。不把实时战斗误称为现有叙事d20已经支持。
### 小游戏
修理：观察3个零件连接、选择并旋转/安装，教学不计时，可撤销。
钓鱼：收线/松线控制张力，观察鱼动，脱钩可重试；一次捕获一个持久物品，奖励有上限。
观察拼合：4–6块照片/地图，放大观察，错放有反馈，不伪造已完成。
小游戏与战斗共用进入/退出/恢复/结果接口，玩法各自独立。
### 动态内容
固定道路、主线、人物和安全出口；可生成工作间/船舱等受限支线。仅用已知事实，限制新增物品与奖励，固定已准入布局。两次连续生成需要后次使用前次已提交知识。媒体未完成可以先探索壳；敌人、预警与关键障碍未完成不得开战。失败仍可返回固定世界。生成与模型可用性分开验收。
### 实验
1. 同一战斗内核运行近战击败和远程到达，接入端只改配置；否则兼容性不通过。
2. 30/60/120fps回放相同输入结果一致，碰撞穿越/重复伤害零发生；否则修内核。
3. 断线、重复请求、退出重进不重复奖励、不把失败说成完成。
4. 实际手机连续探索至少5分钟；桌面模拟不可冒称iPhone通过。

## 4. Controls
触摸圆摇杆移动，松开归零；右侧行动onPointerDown。键盘WASD/方向键，E互动；战斗J/空格攻击、K/Shift闪避。地图拖动缩放，点击地点确认旅行。滚动列表click；对话按页阅读，翻完当前回复后再显示下一组选项；输入控件不吞字母键。音量右上角。战斗中隐藏普通互动按钮，保留暂停/退出。

## 5. Win / Lose Conditions
主线有集市开放的章节收束，随后继续生活探索，没有永久Game Over。挑战有成功、失败、主动退出与恢复；不把断线当失败。资源不足可免费回家休息、选择不付费路线。重开须明确确认，保留或明确选择旅程。

## 6. Sound Effects
正式音乐/环境/动作声音走平台媒体服务。城镇轻木吉他和电钢琴、港口较低音色与稀疏节拍、海岸气音木管、山坡轻原声纹理，45–90秒自然结尾；地点内不因开面板重播。切磋短打击乐，退出回原地点音乐。脚步轻短50–120ms，门扣150–300ms，拳击单次干闷敲击100–200ms，重要成果1秒以内柔和铃音。手势解锁，页面隐藏暂停，静音持久化，最多4个事件音并发。音乐与音效需听感与峰值检查，生成成功不算通过。

## 2026-10-01 本批对白与账号验收

- 序章分开交代来历、住宿目标、移动操作；先认识玛拉，再显式自由提问。手动发问后真实回答，可继续追问或领取钥匙。网络失败保留问题，作者路线不锁死。
- NPC 回复按页由玩家继续；阅读未完成时不显示后续选项。关闭、刷新恢复同一人物/旅程的原回复，无重新提交与奖励重放；语言切换从该回复第一页开始。
- 问题以已知事实为前提，稳定话题 ID 与已完成记录保留。实际完成的 AI 问答才算体验过自由对话。
- 两个独立登录环境验证同账号续玩，另一个账号和登出不得看到前账号资料。浏览器身份与模拟账号测试不能代替真实 AlterU 验收。
- 本批不部署；新增凭据/安全权限先问用户。人类引导理解仍为 comprehension unverified。

## 2026-10-04 全局自由输入举例（本地候选）
