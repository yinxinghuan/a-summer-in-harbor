# 天气生态候选的复验经验

只读查询不创建政策 pin。新增政策从首次确认的当前游戏分钟开始，沿原 CAS 与 compact delta 结算；关闭新开始仍必须保留已固定政策的读取和结算，不能退回不认识新字段的旧代码或数据库快照。

薄荷雨助只减少当前已开始的原生 v2 恢复截止分钟。按游戏日封顶60，不能给叶子、增加株数或把离线墙钟当游戏时间；分段和一次结算必须一致。固定旧版本定义不借用新规则。

动物出发点要把整个碰撞体放进原活动区，不能仅检查脚点。下雨和分钟更新在同一场景/日程区间保留实际脚点，沿既有障碍和身体间距走向遮蔽；放晴在同一区间安全返回，时段更换遵守原日程。路径受阻就等待，不把旁边露天点冒称遮蔽。

碰撞合法不证明视觉可见。最初站街和庭院树下脚点被房屋/树冠遮住，十项机械通过后仍退回；调整既有树旁脚点，再实际检查两个手机尺寸的原 Main/View/RPGJS、连续视频和停步画面。空间投影必须分清 market 逻辑坐标与连续地图偏移。

旧动物观察样本有固定证明合同。新增雨躲避不能改写旧样本，也不能把雨中待着解释为晒太阳观察；本候选保留旧 reader，并拒绝新增雨中晒太阳样本。

截图需等待现有肖像加载并再过两帧。320中文丹妮早期截图曾出现未加载空框；仅补查同一普通本地合成场景，确认 PNG 已加载，没有重生成或替换人物图。

本地合成身份与隔离 SQLite 可证明机制和 UI，不能证明真实平台登录、Telegram、物理手机、跨设备或新玩家理解。正式发布字节与登录后的玩法验收分别记录。
