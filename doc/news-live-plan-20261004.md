# 本地真实资讯采集切片

承接3c409374，不覆盖旧候选或素材锁。仅本地显式CLI采集，未新增后台服务、凭据、付费模型调用或持久排程。

可做范围：使用官方公开RSS，固定HTTPS白名单请求；记录发布时间和真实抓取时间、URL/文本hash去重；同URL变化追加版本并暂缓新事件，定期失效通过读取时判断；已发生选择保留原来源版本，可显示后来变更。过期信息不伪装及时资讯。

首个源选美联储公开货币政策RSS（官方入口 https://www.federalreserve.gov/feeds/feeds.htm），对应虚构金融从业者在丹妮留言簿中的预算核对提议。事实只引用RSS标题与日期；不推断利率对游戏的经济影响，不作投资建议。有限作者模板消费通过准入的事实，模型接口只有messages，当前不增加或假称检索/模型调用。游戏继续用既有权威存档保存选择与确切source revision。

运行链：一次手动采集 → 本地文件原子存档 → 当次本地服务读取 → 新旅程获得一条合格资讯 → 丹妮提议 → 接受/先问需求/暂不参加 → 有限支线结果 → 重载保持。已有旅程内容不因新标题静默替换。更正/失效优先关闭新选用，历史选择不删除。

严格约束：仅固定源ID，禁任意URL；TLS验证、DNS公网IPv4钉住、禁止重定向、总时限10秒、响应512KiB上限、无外部实体XML解析、标题限200字符；网页输入只作为文本。RSS缺时间、未来时间、非白名单链接、超龄或可疑指令内容不可准入。失败保留旧版本但时效不续命。前端原文链接也限相同白名单。

先检验一次真实采集；然后用合成变化/过期/恶意数据验证防线，不能声称真实来源发生过更正。若公开源不允许读取或实际不可达，记录明确响应并停止该源，不绕过访问限制。
