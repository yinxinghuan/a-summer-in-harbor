# 原生蟹游戏消费者切片（编码前合同）
## Overview
延续开放海湾长线探索；本地测试一次约2分钟，可随时停止。正式持久状态仍是原观察/居民关系/知识收藏；本切片原生蟹不写档。目的是让已批准的原生动作真正沿安全岸边横移，并在玩家靠近时安全退避。
## Visual Design
延续原像素场景/真实RPGJS renderer。九个固定原生源，三原站姿+六步态；右向仅完整镜像。整帧透明化、最近邻缩放、根锚平移和装配；禁止局部肢体变形。英文主流程、中文可切换。几何诊断不进入玩家UI。
## Game Mechanics
每帧最多40ms、停留0.8秒、普通18/退避26世界单位/秒、16单位步幅；小于68接近、至少92恢复、最多64横向退避。无安全空间隐藏，障碍不跨越；停止画站姿。地面扫掠面按八足与低壳校准、显示包络另保留8单位间隔。不会追玩家或触发道具/奖励。每分钟/场景改变按当前权威时段重新投影，无离线追赶。
## Controls
原方向键/点击行走；QA面板44px按钮切换运行、暂停、阻挡、重置。直接行走的靠近是动作→退避→下一决策；没有新玩家理解证据，comprehension unverified。
## Win / Lose Conditions
无短局得分、胜负或Game Over。玩家可留空间观察、停止或离开；被堵时安全停留/隐藏，恢复后重新投影。本地观察候选不能自领正式proof。旧档不新增蟹记忆。
## Sound Effects
沿用原脚步；蟹动作无新音效、无新生成。AI只选择固定既有猫/鸥观察事实及居民主题；自由正文不能成为作息或奖励规则。
