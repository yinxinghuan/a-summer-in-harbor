# 本轮技能补充候选（已验证与未验证分开）

## 已验证可复用合同

1. 人物从常驻改为日程时，同时改renderer可见性、命中/碰撞、动作准入、日程提示、任务位置及模型上下文；不能只加几张路线表。新手关键人物可在关键交付前等待，完成后恢复生活日程。屋内活动要绑定物理场所（拳馆/钓鱼/商店），不随人走到路边。
2. 使用同一旧NPC素材时仍需检查连续步态、完整巡游走廊可走、接近停步和旧存档重叠逃逸；旧的“找到任意含NPC的房间”测试fixture在多地点后失效，应选择该时段实际位置。
3. 玩家跨时段后主线NPC可能离开：完整章节测试要通过合法回家睡觉/再访继续，不能注入时钟或放宽PERSON_AWAY掩盖问题。门口公开营业信息；已认识且问过日程的人物可显示当前/下个地点。
4. 作物生长用已提交游戏分钟，保存湿润终止点与累计生长；缺水暂停，成熟保留；休息跳时和短动作推进采用同一结算方法。旧存档缺字段按空菜畦，不把观赏植物历史当作种植收获。
5. 金钱、种子、产物、田块状态必须在同一权威action事务中修改；同ID重复、异ID同版本并发、丢回复和重启分别测试。钱包达到上限时拒绝出售并保留货物，不先删除再截断收入。
6. 资讯事实与NPC虚构提议分开。冻结source record含真实来源/时间/版本，持久选择只触发有限已授权的世界变化。普通LLM对话不等于运行时联网能力。
