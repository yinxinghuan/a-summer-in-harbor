# 室内外丰富度与朝向复验 · 2026-10-01

## 范围与结果

本轮接续此前像素 UI / 道路打磨，覆盖 12 室外、8 室内以及 2 个修理铺附属小间。保持北美海湾背景、en/zh、现有对白与引导。只本地预览，不部署，账号等待同事。

室内参考《星露谷物语》的生活痕迹和用途分区，不复制其素材。餐饮、零售、修理、运动、气象和灯塔分别增加符合用途的独立家具。室外加入大小树木、灌木、花草、菜床、手推车、单车、船与系船桩。重点物件保留空地和通行间距。

## 出图与准入

- 本轮 29 个独立平台请求（23 件新内容 + 5 张朝向图 + 1 张侧桌修正）。`gpt-image-2.5-sunburst`、high、1024²，全部 `mode:text`、reference_count=0。
- 28 张在当前 renderer 使用；`dining-table-side-v1` 因梯形透视淘汰，改用 v2。失败稿保留审查记录，不进入运行场景。
- 长椅 3 朝向沿用上一轮；餐椅前/背/侧、餐桌长边/短边、自行车侧/正面建立家族映射。不是平面旋转或镜像冒充新结构。纯文生图的磨损细节并非逐像素一致，不据此宣称任意角度稳定。
- `doc/art/richness-catalog-20261001.json` 保存分类、源请求、模型、无参考证明、SHA、实际场景尺度、碰撞和朝向关系。只做项目元数据，没有建共享资产服务。生成来源不等同独占版权声明。

## 检测中修复

1. 修理铺附属小间新椅子与观察点重叠：椅子下移，保留原观察点。
2. 侧桌纵深增大侵入西奥谈话接近点：整组桌椅右移，未缩假碰撞。
3. 海滩南边水面原来是有限矩形：延伸至地图边缘，视觉与水碰撞仍共用地形。
4. 相交道路铺砖起点不一致造成拼接缝：全部地形块使用同一世界坐标铺砖起点，保持缓存底图。
