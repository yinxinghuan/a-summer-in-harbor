# 小镇生活与资讯故事：本地整合验收

基线为已发布居民植物版本 `5fcc3f411fb7b0160b7f2bd3bc590237260226dc`。本轮只在独立副本修改；未部署、未新增媒体调用、未修改正式数据库或账号接入。居民植物生成保持停止，历史累计46/72。

## 实现

- 原9位与新增4位居民共13位的时间表、场景内巡游、场所限定活动、已学习的日程提示；Mara等关键交付人物先保障序章可完成。
- 夜色与入口灯光；清醒时间疲劳与回家休息，不对离线时间施加惩罚。
- 萝卜、罗勒、番茄3作物的播种、浇水、成熟、收获、商店出售和购种，共用原现金与权威存档。可缺水暂停，不会枯死。
- Dani游客簿里的单条真实来源示例：事实来源、虚构游客提议、分支选择、校对营业时间、持久记忆与花园告示。新闻为开发时核实的冻结资料，不是游戏内实时采集服务。

## 证据

- Node完整回归82/82，含并发收获/售卖、重复请求、丢回复、重启与不同owner隔离。
- `report.json`：320/390/1024布局共11状态，0页面错误，0美术请求失败。
- `loop-report.json`：同一合成中期旅程，普通按钮与点击行走完成播种→浇水→回家小睡两次→收获→出售→购种→重载；没有中途注入时钟、坐标或存档。最终余额28，库存与版本正确。
- `render-report.json`：原9位居民实际renderer连续步态，以及夜间入口光效，共10项通过。
- TypeScript、Vite构建、公开凭据与API Base检查通过。生产PostgreSQL和iPhone硬件不在本轮本地验收范围。

## 交付边界

这是一份已做功能与浏览器验收的本地候选，尚不声明整批新增内容高保真发布就绪。作物用编号菜畦展示状态，独立作物三阶段/产物美术尚缺；新专业游客暂无独立精灵；工具升级未实现。真正的运行时资讯采集、更新/失效/更正与生成事件准入未实现，也未调用对话模型验证。新玩家理解度未验证。

复用发现写入 `doc/townlife-skill-findings-20261004.md`，是有证据的候选条款，不代表已修改共享Skill。原居民/观赏植物批次与这些新增作物美术分开，不自动重新启用生成额度。
