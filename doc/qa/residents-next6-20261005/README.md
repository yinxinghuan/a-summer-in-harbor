# 6位居民本地候选 · 2026-10-05

基线为已发布战斗修复c3558b07。独立源码`/private/tmp/harbor-validation-20261005/residents`；保留原dirty工程。未部署，未改变正式13位居民或线上玩家存档。用户直接批准本地新增6位，职业以最后一条明确列表为准。

## 实现
6位新居民共用既有RPGJS renderer、权威规则、存档、人物关系、日程与对话历史。名册总19位，各自上午/午后/傍晚地点及24单位巡游范围，夜间休息、接近面向玩家。原13人生活与主线不变。每人有职业、个人活动、与一位原居民的联系及独立分支故事。

每条故事从初识、了解问题、向另一位居民征询意见、回来二选一、一次性关系进展、回访组成。要求先认识、亲自问到相关意见；答案不抢先出现。已说话题隐藏、历史保留；夜间错过次日可继续，关系页给出下一目标及其当前房间。主线任务、钱包和道具不会被这些小故事自动修改。两种结果各有具体记录，不把“计划”描写成已举行活动、已采购或已修好设施。

`src/story/next-residents.json`存成对中英内容与固定角色/库计划；`next-neighbors.ts`负责前提、两种结果、只提交一次、日程指向、自由对白上下文和举例；`binding.ts`注册全部新动作及旧居民新增答复。没有新模型或检索依赖，离线 authored 路径可完成全部6条故事。
