# 本地可玩版验收 · 2026-10-01

## 范围与结论

本次交付本地可玩的首章与开放探索，没有发布到平台。20 个作者地点（12 个室外、8 个室内），另有最多两代生成线索地点。五个地区枢纽是 1440×1088 世界里的较大室外区域；建筑、岸线、路径和物件各有占地，不是给普通房间换名字。

构建、规则测试和桌面浏览器操作已验证。`comprehension unverified`：没有新玩家复述/行为证据；未宣称 60–90 分钟游玩目标已经达成。测试含阅读、服务等待与改错，不能作为净游玩时长。没有真实 iPhone AlterU 持续性能证据，也没有人工音频听检；这些不记为通过。

## 真实玩家路径

同一个正常存档，使用界面操作而非注入 flag：

1. 开场 → 玛拉介绍 → 领取钥匙 → 回租屋放行李。
2. 地图返回车站街；自由输入询问玛拉得到真实平台答复。
3. 咖啡馆认识西奥 → 取工具袋 → 操作三个接头 [1,3,2] 修灯 → 归还袋子。
4. 读集市告示 → 港口/海岸/滨海道查看破桥 → 琼的介绍和借工具。
5. 贝壳海滩拾取两块木板 → 修桥（木板扣除、体力变化、图像及阻挡同源更新）。
6. 灯塔设置海岸通行 → 地图快返已到访集市 → 分享消息 → 摊位开放。
7. 关闭互动后仍可探索；刷新仍在集市，任务提示保持“Summer continues”。

证据：`_qa/chapter-complete-platform-layout-390.jpg`，此前阶段截图与 `doc/playtest-progress.md`。修桥路线通过真实 UI；另外两条通行分支有规则实现，未在第二个全新玩家存档完整走通，不把它们算作三次人工通关。

## 渲染与界面

- 22 个当前渲染地点逐个通过开发诊断页选择并截图。诊断页不写玩家存档，不能冒充真实主线完成。
- 发现并修复 Market Lane / The Hill 地面整层缺失：有界作者场景禁用按事件原点裁剪的默认 MMORPG streaming。相同场景重截正常。
- 检查 390×844 与 320×568 地图；已到访地点快返实际使用；放大与横向拖动实际操作，见 `map-pan-platform-layout-390.jpg`。双指手势规则测试有覆盖，未在真实 iPhone 做双指实测。
- 1024×768 室内相机对齐修复；小房间宽度不足时，扩展 clamp 边界保持水平居中。北墙在向北移动后可见，见 `room-north-platform-layout-1024.jpg`。人物比例没有为宽屏重新缩小。
- 主角步态、教练巡游及战斗动作使用本次新制素材；没有用旧游戏图片。Mara 未通过移动候选，仅保留站立与面对玩家，不能称所有 NPC 都有合格巡游动画。
- 战斗界面已操作出拳/闪避/退出并检查失败返回；钓鱼界面已检查，规则测试含捕获/失败。没有把脚本模拟结果记成真人手动钓获。
- 平台外访客栏保留；截图使用关闭访客栏后的 platform-layout，未给生产 CSS 增加隐藏规则。
