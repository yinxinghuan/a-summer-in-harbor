## 改动

- `question-examples.ts` 是本游戏的只读作者适配器；使用已有 questProgress 完成优先级，每个 NPC 至少两条中英短例子。未知人物、缺少地点或不匹配上下文使用无剧情前提的泛问。
- `ExampleAssist.tsx` 是受控写作辅助组件；举例/换一个只写可编辑草稿，不包含 fetch、模型、发送或权威状态依赖。现有未编辑的例子可轮换；用户文字、改写后的文字和刷新恢复的草稿先预览，经明确“替换”才改变。保留草稿不改内容。
- 父级沿用原部署/旅程/人物草稿键与手动发送，上下文key在相关进度、地点、人物、旅程或语言变化时重置助手临时状态，不清用户草稿。请求中或结果未确认时禁用辅助与输入；失败保留草稿。
- 不再仅以 hasAsked=false 显示。仍尊重未读回复，全部回复页读完后才进入输入阶段。
- 触控发现并定向修正：打开面板的 pointer-down 后，尾随 click 可落到新遮罩导致立刻关闭。遮罩改为只响应直接落在背景上的 pointer-down；内部滚动/按钮、显式关闭与 Escape 保留。没有改场景或玩法。
