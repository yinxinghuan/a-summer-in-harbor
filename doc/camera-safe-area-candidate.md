# 镜头安全区候选（实施前合同）

基线为正式前端 2e1e20e；本轮只制作本地独立候选，未获发布批准。国际用户、虚构北美沿海小镇、新来租客身份、中英文流程和像素视觉体系均沿用。

直接探索时，角色到达原有上下边缘及四角仍保持中央安全带。镜头的逻辑可走范围、已有视觉范围和额外渲染范围分别计算。必要外围用现有合法地面纹理补齐，只供画面，不扩碰撞、通行、世界坐标、速度、旅行时间、日程、经济或存档。

安全区由真实 header/location/objective/controls 矩形与 CSS safe-area inset 得出。标题和目标换行、语言切换、resize、面板开关后重测；共享 guest-shell 不参与主构图，也不改其源码。宿主若已缩小 iframe，游戏从实际子视口取值；父宿主覆盖但未向子 frame 提供 inset 时游戏无法凭空推知，须保留 host 证据缺口，不能写死假 UI 高度。

验证实际 Main/View/RPGJS 的 320×568、390×844、桌面，上下/四角、室内外大小场景、日夜、移动/停步/互动、resize、面板、中英文。画面几何距离依据真实 sprite frame + alpha 和 DOM 遮挡矩形；fixture 不冒充 Telegram / 物理手机。
