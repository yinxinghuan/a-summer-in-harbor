# 最新 RPG 技能试用评估

本次用独立项目《海湾新生活》验证。没有打开旧游戏美术作为参考，也没有复制旧游戏剧本或整套 UI。根素材由平台文本生成；新角色身份图派生姿态、同批门修正使用了明确记录的参考编辑。两种能力必须分开描述。

## 已经实际使用的能力

| 能力 | 本轮使用与证据 | 可复用边界 |
|---|---|---|
| RPGJS 空间壳 | 新工程、独立 UUID、真实显示人物/家具/墙地、连续转场 | 可复用装配合同，不把 React UI 当成引擎 |
| 室内模块与室外世界 | 8 室内、12 室外作者地点；5 个大户外地区 | 户外独立地形、水岸碰撞、地标、两轴镜头；不能套房间四墙 |
| 平台美术 | 请求/原件/SHA、透明化/裁切/图集、同屏 56 单位身高 | 根图无历史参考；同轮姿态编辑不是纯文本一次成功 |
| 对话/背包/地图 | 首次介绍、延迟选项、自由问话、已读退休、手记、已访快返 | 固定结果仍经权威规则；不能凭模型台词发奖励 |
| 通用动作玩法 | `combat/core.ts` + 三份配置 + 输入回放验真 | 算法不依赖本游戏角色/场地/图片；UI 和素材由消费游戏提供 |
| 持久权威 | 冻结 async 候选 + 当前游戏适配器 | 本地 SQLite 实证，不冒充 PG 或平台账号生产认证 |
| 两代动态内容 | `doc/qa/live-fieldnotes-v4.json`、Prolog 检验、只增知识、安全返回 | 最多两代固定几何地点；不是无限地图或任意新碰撞物件 |
| 游玩时媒体 | `doc/qa/note-media.json` | 真正平台生成、稳定任务、旁路保存；此处为细节图，不是新正交地图资产 |

## 应补入技能的具体内容

### P1：大图层的原点不能决定整张图是否可见

本轮市场街、山坡的出生点距离地图左上角较远。RPGJS 默认 Tiled 区块 streaming 按对象原点准入，造成整张地面消失，人物和部分家具却仍可见。小屋检查和“地图名正确”都无法发现这个问题。

修正：此有限作者地图使用 `tiledServer({basePath:'./map', streaming:false})`，仍保留 RPGJS/Pixi 缓存和相机。已在相同出生点复拍市场街/山坡。技能应要求覆盖最远出生点和地图四边，检查实际纹理；真正流式大世界必须对跨区块视觉范围设计准入，不能无条件关闭 streaming 后宣称支持无限世界。

### P1：生成内容的语义审查不是一张通过票

前几轮候选机械检查与模型审查都通过，但实际存在“说有可用材料却不能拿”“下一代重复上一代”“琼不在场却突然开口”等问题。记录仍保留，不能用最后一轮覆盖失败证据。

本轮把两代观察的主题差异、角色在场边界、知识递进写进提示和准入；v4 的木材受潮观察转到工具锈蚀/通风架，玩家自己观察推断，无新奖励。还修正了一次过宽正则把“说明”误认成角色“说话”的审查错误，沿用缓存请求复核，没有默默另发生成。

技能应增加：来源事实→本代新增知识→可操作行为→后果逐项对照；引用人名要有双语身份表；第三方模型“passed”不得代替人工玩读和否例检查。

### P1：动作素材与玩法配置同时验收

站姿正确不能证明巡游和战斗动作正确。Mara 的移动候选没有通过，所以只保留转向；Idris 使用明确相反支撑腿的两相动作，游戏中巡游。战斗另有四方向预备/出手图，不拿走路图旋转冒充攻击。

通用战斗应收录：固定步进、阶段、单次攻击目标集合、闪避无敌区间、墙体 LOS、击败/到达/生存目标、退出恢复、输入回放。不同帧率和非法输入测试已覆盖；跨第二题材的攻击美术与操作体验仍未验证，不能直接称“成熟战斗技能”。

### P2：地图标签按触控尺寸排版

图形可以缩放，文字和触控目标不能缩成不可读小点。保持节点可读尺寸后，fit 必须计算节点外扩边界；仅把连线画布 contain 会截掉边缘标签。已改为额外地图留白与窄屏节点尺寸，检查 320/390。

### P2：场景改变必须有同源碰撞与提示

破桥换成完好图时，同时解除缺口阻挡；规则端位置检查和渲染移动读取同一 flag。借到工具后下一步直接提示“贝壳海滩找两块木板”，取得后提示“滨海道修桥”，不让玩家一直记住口头指令。

### P2：音频响度也属于素材准入

平台出音成功不等于可直接混音。本轮脚步/打击原音太响，成果音又过小，已保留原件并做记录在案的响度调整。技能应区分数值削峰、循环衔接、内容听检和实际手机听感；目前只有前两项的程序证据，不宣称人已听过。

## 本轮结论

技能已足够支持独立搭建这一类可玩游戏，但尚不足以承诺“任何 agent 一次生成都自动合格”。尤其不能把模型审查、单张素材、单房间、桌面测试或本地 authority 分别冒充语义、动画、全场景、手机或生产认证。

已将两项有直接证据的规则写回共享技能：`build-spatial-story-game/references/independent-assembly.md` 的室外大场景/图层流送检查，以及 `map-navigation.md` 的固定触控标签与 Fit 留白。其余语义审查、战斗模板、音频听检建议保留在本项目，需跨第二题材复验后再晋升为统一模板。

### 最终界面复验补记

宽屏小房间不能依赖 Pixi `underflow:center` 自动理解自定义房间边界：它检查的是整个 world。应在视口大于房间的轴上对称扩展 clamp 边界，复验各尺寸与移动。场景 DOM `overflow:hidden` 仍能被焦点滚动，非滚动世界应使用 `overflow:clip`，防止 offscreen portal 的 focus/scrollIntoView 把画布移走。两项已经用于本游戏并截图，作为本地补充候选，不宣称已写回全部技能副本。

## 2026-10-01 最新对白技能复验

- 采用 create-rpg-game 的 free-dialogue-onboarding 与 dialogue-continuity，新增知识前提、明确翻页、关闭/刷新恢复、真实自由提问与失败恢复；本地27测试、两尺寸、中英文真实请求通过，详见 `qa/dialogue-onboarding-20261001.md`。这说明本作已应用规则，不代表用户理解或所有游戏自动通过。
- 发现跨技能身份表述需要统一：旧 rpg-story-session-production 的 capability 云同步建议与 get/data/list 的跨用户可见性相冲突；game-persistence 的“跨设备存档”不能自动等同于本作 PG 账号认证。旧平台代理 resolveVerifiedActor 有可复用边界，但仍需真实验证器。
- 本次未向共享技能登记“真实账号接入已交付”；用户要求实际跨设备与不同账号通过后再写回，这一验收尚未完成。历史证据索引在 `account-storage-integration.md`。
